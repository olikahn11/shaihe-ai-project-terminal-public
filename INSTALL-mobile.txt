沙禾项目终端 · 手机端使用与安装指引

沙禾项目终端支持两种手机端使用方式，请根据您的偏好选择：

============================================================
方式一：iPhone / Android 浏览器免安装即用（强烈推荐，最快捷）
============================================================
1. 在 Mac 上的沙禾项目终端，打开「设置 → 手机远程总控」；
2. 打开手机相机，直接扫描 Mac 屏幕上的「局域网扫码」二维码（如跨网络，两端登录 Tailscale 后扫描异网二维码）；
3. 手机 Safari 打开后即可直接操控 Mac 上的所有 AI 任务；
4. 【推荐技巧】：点击 Safari 底部的「分享」图标，选择「添加到主屏幕」。
   系统会自动在手机桌面生成一个独立的 App 图标，打开后全屏无地址栏，体验与原生 App 完全一致！

============================================================
方式二：iPhone 安装原生 IPA 遥控包（全能签 / TrollStore / 证书自签）
============================================================
安装包文件：Shaihe-Terminal-Remote-4.4.9.ipa

【全能签（Esign）安装步骤】：
1. 将 Shaihe-Terminal-Remote-4.4.9.ipa 发送到手机或使用 Safari 下载至「文件」App；
2. 打开「全能签」App，点击右上角「+」或「导入」，选择该 IPA 文件；
3. 在已导入的应用列表中，点击该应用，选择「签名」；
4. 选择您的有效个人证书或企业证书，点击「立即签名」；
5. 签名成功后点击「安装」即可在手机桌面获得「沙禾项目终端」原生应用。

【巨魔商店（TrollStore）安装步骤（iOS 14.0 - 17.0）】：
1. 在 iPhone 上使用 Safari 或隔空投送接收 Shaihe-Terminal-Remote-4.4.9.ipa；
2. 点击分享按钮，选择「在 TrollStore 中打开（Open in TrollStore）」；
3. 点击「Install」，即可实现免越狱永久原生安装。

【Sideloadly / AltStore 免费 Apple ID 自签】：
1. 在 Mac/PC 上打开 Sideloadly，手机连接电脑；
2. 将 Shaihe-Terminal-Remote-4.4.9.ipa 拖入 Sideloadly，输入个人 Apple ID 签名安装即可。

============================================================
安全性说明
============================================================
- 手机端仅作为遥控终端，不保存任何模型账号、密码、Token 或项目代码；
- 每次配对使用随机 Token 进行端到端加密验证；
- 手机锁屏或断开网络，Mac 上的长线任务依然在 tmux 后台平稳运行，重连后自动恢复显示。
